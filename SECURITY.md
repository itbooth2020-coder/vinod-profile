# Security policy

This repository is the source of Vinod Yadav's portfolio site, [www.vinodyadav.com](https://www.vinodyadav.com): a static site on S3 and CloudFront, with no accounts and no stored visitor data.

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue:

- Use GitHub's **Report a vulnerability** button (Security tab), if it is shown, or
- Email Vinod through the **Email** link in the site's contact section ("Let's connect").

Please include the page or file, the steps to reproduce, and what an attacker could gain. You can expect a first reply within 5 working days, and a fix or a plan within 30 days. Please give a reasonable time to fix before disclosing publicly.

## Scope

- In scope: the published site, this repository and its build and deploy workflows.
- Out of scope: third-party services (GitHub, AWS, Blogger, Google Fonts), denial of service through volume, and reports from automated scanners with no demonstrated impact.

## Supported versions

Only the current `main` branch and the live site are supported.
